# 🚀 Ian Gross Sánchez — Portfolio

A high-performance personal portfolio built with **Eleventy (11ty)**, featuring Aerospace-themed aesthetics, glassmorphism, and optimized SEO.

## ✨ Features

- **Aerospace Aesthetics**: Deep space theme with animated gradients and glassmorphism.
- **Fluid Design**: Fully responsive layout using modern CSS `clamp` and grid systems.
- **SEO Hardened**: 
  - Dynamic `sitemap.xml` and `robots.txt`.
  - JSON-LD Person Schema for professional indexing.
  - Comprehensive Aerospace & Engineering metadata.
- **Premium UX**: Smooth scrolling, custom scrollbars, and micro-animations.

## 🛠️ Development

### Local Server
To start the development server with live reload:
```bash
npm run dev
```
Alternatively:
```bash
npx @11ty/eleventy --serve
```

### Production Build
To generate the static site in the `_site/` directory:
```bash
npm run build
```

## 📂 Project Structure
- `src/`: Source files.
- `src/_data/`: Global data files (e.g., `site.json`).
- `src/_includes/`: Layouts and partials.
- `src/css/`: Vanilla CSS styling.
- `_site/`: Generated static files (deploy this!).
